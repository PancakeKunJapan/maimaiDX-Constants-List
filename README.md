# maimaiでらっくす 譜面定数表

maimaiでらっくすの譜面定数の一覧表です｡  
**15~14+までしか対応してません｡**

---

## 見方･使い方

### 楽曲の検索・絞り込み

- **検索機能**: 楽曲は**曲名**または**アーティスト名**で検索できます。
- **Version Filter**: 楽曲のバージョンを絞り込みできます（「全選択」「全解除」のボタンで一括操作が可能です）。

### 表示のカスタマイズ

- **表示モード**: 以下の3つのモードから表示を切り替えられます。
  - ジャケット ＋ 曲名
  - ジャケットのみ
  - 曲名のみ
- **表示サイズ**: ジャケットの表示サイズを変更できます（※表示モードが「ジャケット＋曲名」または「ジャケットのみ」の場合に有効）。

### 難易度・定数の確認

- **難易度切り替え**: 以下の各ボタンを押すことで、それぞれの難易度ごとの定数を表示できます。
  - `MASTER`
  - `Re:MASTER`
  - `EXPERT`
  - `ADVANCED`
  - `BASIC`
- **SORT（並び替え）**: 楽曲を**バージョン順**、**定数順**、**曲名順**に並び替えできます。
- **カードの見方**:
  - カードの左上には**譜面タイプ（DX譜面かSTD譜面か）**、**曲名**、**アーティスト**が表示されます。
  - 下部の各難易度カラーの枠内に書かれている `00.0` という数字が**定数**です。

### ジャンルカラー（ボーダー）

カードの左側（ジャケットのみモードの時は下側）のボーダー色は、楽曲のジャンルを表しています。

| ボーダーの色 | 対象ジャンル       |
| :----------- | :----------------- |
| 🔴 **赤色**  | オリジナル         |
| 🔵 **青色**  | ゲキチュウマイ     |
| 🟢 **緑色**  | ゲーム＆バラエティ |
| 🌐 **水色**  | nico＆ボカロ       |
| 🟡 **黄色**  | POPS＆アニメ       |
| 🟣 **紫色**  | 東方Project        |
